## Русский

Настройки отображения карты Viking Rise для Windows.

**Текущий выпуск: 1.4.10 beta.** Доступен всем в основном канале обновлений.
По сравнению с 1.3.1 добавлены настройки текстур и окружения для обычной карты,
семейств КвК 1–10 и повторных сценариев, а установщик получил оформление
в стиле TeamWits с фьордом и постоянно видимой панелью установки.

- Треугольники маршей при любом приближении; NPC отмечены оранжевым.
- Сокращение декоративных эффектов, чисел урона и следов движения с сохранением меток и указателей атаки.
- Выбор показа рамок своих и союзных героев.
- Отдельный переключатель вражеских аватарок со штатными полосами ХП.
- Облегчённые города: компактные иконки без ников и декоративных плашек.
- Текстуры карты: «По игре», «Средние», «Низкие»; интерфейс остаётся чётким.
- Отдельное сокращение декоративных частиц и анимаций окружения.
- Круглая кнопка TeamWits под списком маршей и сохранение настроек.
- Автоматические обновления обычного экземпляра через меню, без перезапуска игры.
- Все 16 языков игры, включая сообщения обновления и подтверждение удаления.
- Удаление из меню с подтверждением и восстановлением обычного вида игры.
- Установщик RU/EN с выбором языка по Windows и ручным переключением.
- Выбор обычного запуска, Sandboxie или обоих вариантов; настройка существующих песочниц.

Установите приложение, откройте карту и нажмите логотип TeamWits под списком маршей.
Подключение происходит автоматически. Поддерживаемые версии Steam:
**1.5.160_201867** и **1.5.170_204133**; официального клиента IGG — **1.5.160_201867**.
Новый IGG 1.5.170 отдельно не проверен. Если игра запущена от администратора,
приложение запрашивает соответствующие права через стандартное подтверждение Windows.

Если после обновления игры значок пропал в прежнем March Display, запустите
установщик последнего релиза. Настройки сохранятся. Начиная с 1.3.1,
обычный фоновый экземпляр может получать обновления и до подключения к игре.
Для изменённой версии игры всё равно нужен совместимый выпуск March Display.
ПКМ и перетаскивание на нифлунга проверены в Steam 1.5.170; живая проверка
вражеских ХП в бою пока не выполнена.

Новые графические настройки по умолчанию выключены. Вживую проверены обычная
карта и КвК 8; другие семейства карт проверены по каталогам ресурсов и тестам.
Прирост FPS новыми режимами отдельно не измерен и зависит от сцены и компьютера.
После смены карты применение настроек может занять несколько секунд.

Для Sandboxie запустите установщик вне песочницы и отметьте нужные существующие
песочницы. Перед установкой завершите программы в них. Затем запускайте по одному
клиенту игры в каждой: модуль подключится автоматически, настройки отображения
сохраняются отдельно. Обновление и удаление общей установки выполняются вне
Sandboxie после закрытия изолированных экземпляров. В режиме «только Sandboxie»
новую версию устанавливают внешним установщиком.

## English

Map display settings for Viking Rise on Windows.

**Current release: 1.4.10 beta.** Available to everyone in the main update channel.
New since 1.3.1: texture and scenery controls for the regular map, KvK 1–10 map
families and repeat scenarios, plus a TeamWits-style installer with fjord artwork
and persistent installation controls.

- March triangles at any zoom level, with orange NPC markers.
- Reduce decorative effects, damage numbers and movement trails while keeping map markers and attack indicators.
- Choose whether to keep your own and allied hero frames.
- A separate toggle for enemy portraits with native HP bars.
- Lightweight cities: compact icons without names or decorative nameplates.
- Map textures: Game, Medium or Low; the interface stays sharp.
- Separate controls to reduce decorative particles and scenery animations.
- A round TeamWits button below the march list, with saved preferences.
- Automatic updates for the normal instance from the in-game menu, without restarting the game.
- All 16 game languages, including update messages and uninstall confirmation.
- Uninstall from the menu with confirmation and restoration of the normal game display.
- A RU/EN installer that follows the Windows display language and allows switching.
- Choose normal launch, Sandboxie or both, and configure existing sandboxes.

Install the app, open the map and click the TeamWits logo below the march list.
The app connects automatically. Supported Steam versions:
**1.5.160_201867** and **1.5.170_204133**; official IGG client: **1.5.160_201867**.
IGG 1.5.170 has not been separately tested. If the game runs as administrator,
the app requests matching permissions through the standard Windows consent prompt.

If the icon disappeared in an older March Display after a game update, run the
installer from the latest release. Your settings are preserved. Starting
with 1.3.1, the normal background instance can receive updates before connecting
to the game. A changed game version still requires a compatible March Display
release. Right-click and drag-to-attack were tested on a Niflung in Steam 1.5.170;
enemy HP updates during combat have not yet been tested in-game.

The new graphics options are off by default. Tested live on a regular map and
KvK 8; other map families were checked through resource catalogues and tests.
Additional FPS gains from these modes have not been measured and depend on
the scene and PC. Allow a few seconds for settings to apply after changing maps.

For Sandboxie, run the installer outside the sandbox and select the existing
sandboxes you want. Close applications in them before installing. Then start one
game client per sandbox: the module connects automatically and keeps separate
display settings. Update or uninstall the shared installation outside Sandboxie
after closing sandboxed instances. In Sandboxie-only mode, install future versions
using the external installer.
